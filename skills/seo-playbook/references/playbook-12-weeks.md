# 12-week plan and self-check (playbook Stage 9)

Write two lines at the end of each week. Every four weeks, half an hour against the start.

## 9.1 Timeline

| Week | Area of work |
|---|---|
| 1 | Benchmark: save the starting heatmap and the top-10 sheet. Start asking for reviews and taking photos. |
| 2 | Starting on the profile: main keyword chosen; categories and profile completion. |
| 3 | Completing the profile: services list, descriptions, bookings, FAQ. The weekly routine starts. |
| 4 | Self-check 1 on the profile work so far. |
| 5 | On-page SEO basics: title tag, headings, NAP, map embed. |
| 6 | On-page: content inventory. What Google has indexed, and what topical and local content is missing. |
| 7 | On-page: writing the pages. New service and area pages in progress. |
| 8 | Self-check 2, and list what's left on the website. |
| 9 | Citations start: the core listings. Keep the phone at hand for verification codes. |
| 10 | Citations continued: directories that rank for the keyword; competitor sources. |
| 11 | Rankings check: a new heatmap next to week 1's. Read it honestly. |
| 12 | Week-12 review: self-check 3 and the review in 9.3. Decide what happens next. |

Week 1 = the Monday of the run week. Write real dates in `WEEK-PLAN.md`.

## 9.2 Monthly self-check (`SELF-CHECK.md`)

| What to count | Start | Week 4 | Week 8 | Week 12 |
|---|---|---|---|---|
| New reviews since the last check | | | | |
| Total reviews and average rating | | | | |
| Photos added since the last check | | | | |
| Profile posts published | | | | |
| Services listed on the profile | | | | |
| Indexed pages (`site:` search, step 2.4) | | | | |
| Calls, website clicks and direction requests (profile Performance view) | | | | |
| Position for the main keyword (Maps search or heatmap) | | | | |

Look at the direction across the columns. One month on its own says very little.

## 9.3 Week-12 review

1. Put the week 11 heatmap next to week 1's. Where did you move up, and where not?
2. Read across the self-check: reviews, photos, posts, calls and clicks.
3. Look at the Advanced steps you skipped. Does the market need them?
4. Be honest about the weekly routine. Can it keep running an hour a week?
5. Choose: keep the routine going, start the Advanced steps, or hand the work over.

## If you do this for clients

- Day one: admin login to the site and owner or manager access to the profile; check both.
- Send the 3.6 services list and ask which ones they don't offer.
- Reviews and photos are the client's job. Say so in week 1 and in every update.
- One short email a week: what you did, what's next, what you need. Fuller updates in
  weeks 1, 4, 7 and 12 (week 12 with the week 1 and week 11 heatmaps side by side).
- Don't promise rankings or dates. Keep one checklist per client.
