Source: The Local SEO Playbook, 2026 edition, Stolos Digital. Groups, order and wording
follow the printable checklist in the PDF. "Agent" says what this plugin can check.

| Stage | Pass | When |

| 01 Benchmark | Basic run | Week 1, before you change anything |
| 02 Easy-win checks | Basic run | Week 1 |
| 03 Google Business Profile | Basic run | Weeks 2-4 |

| 05 On-page advanced | Advanced | Weeks 6-8, or when the basics are not enough |

| 08 Fake listings | As needed | Whenever one is spotted |
| 09 12-week plan | Basic run | Weeks 1-12 |

## 04 On-page basics · Wk 5

| Step | Checklist line |
|---|---|
| 4.1 | Title tag rewritten (~200 chars max) |
| 4.2 | H1 = category + city |
| 4.2 | H2s = secondary categories + services |
| 4.3 | NAP on homepage and in footer |
| 4.3 | Profile map embedded on homepage |

Title formula (4.1): BEST (only if you can back it up) + primary category + city +
business name + primary services + "near me" (if space). No repeated keywords. A call
to action belongs in the meta description, not the title.

## 05 On-page advanced · Wk 6-8 (Advanced)

| Step | Checklist line |
|---|---|
| 5.1 | LocalBusiness schema added and validated |
| 5.2 | Page plan: landing > category > services |
| 5.3 | Services hub + one page per service (1,500-2,500 words each) |
| 5.4 | Areas we serve page in main menu |
| 5.4 | One page per area (1,200-2,200 words, only when something true and different can be said) |
| 5.5 | Services and areas interlinked (max 8-10 per page) |
| 5.5 | Links click-tested |

Interlinking (5.5): service page = 2-4 in-text links to areas + "We also serve these
areas" (3-5). Area page = 3-6 in-text links to services + "Services we offer here"
(3-5). Homepage and contact = all areas + main services. Natural, varied anchor text.
Not only in the footer.

## Fake listing red flags (8.1)

Keyword-stuffed name, often in capitals. A location that doesn't fit the trade. A
website with only a phone number and no address. One flag alone proves nothing. Be
100% sure (Street View, the website, a visit) before any report; if there is any
chance it is a real business, don't report it.
